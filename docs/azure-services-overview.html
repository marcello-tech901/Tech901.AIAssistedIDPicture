04

Dependency Injection & Fallbacks

AzureSpeechService Active

Full voice interaction: TTS prompts guide participants, STT captures spoken names with pre-warmed recognizer for low latency.

When: Azure:Speech:Key AND Azure:Speech:Region are set
SDK: SpeechConfig.FromSubscription(key, region)

NullSpeechService Fallback

Silent operation. SpeakAsync completes immediately, ListenAsync returns null. Kiosk works via keyboard-only input.

When: Key or Region missing
IsAvailable = false • All methods are no-ops

AzureFaceService Active

Detects face landmarks to intelligently crop photos centered on the face. Uses Detection03 model with rate-limited API calls.

When: Azure:Face:Key AND Azure:Face:Endpoint are set
SDK: FaceClient(endpoint, AzureKeyCredential)

NullFaceDetectionService Fallback

DetectFaceAsync always returns null, triggering center-crop logic in ImageProcessingService. Functional but less precise.

When: Key or Endpoint missing
Returns null • Center-crop used instead

All service registrations use resolution-time factory lambdas in ServiceCollectionExtensions.cs — factories run at host startup, not registration time, guaranteeing all config sources (appsettings, User Secrets, env vars) are loaded before the active-or-fallback decision is made.

06

Resilience & Error Handling

Polly Retry Policy

Face API calls are wrapped in exponential backoff retries for transient HTTP failures.

3 retries • 2^attempt sec delay
Triggers on: 429, 5xx

Rate Limiting

SemaphoreSlim serializes Face API calls to stay under the free-tier throttle ceiling.

SemaphoreSlim(1, 1)
~1 request per second

Pre-warming

Speech recognizer is created before the user speaks, eliminating SDK initialization latency.

PrepareListenAsync() called
in NameCapture setup

Graceful Degradation

Null-service pattern means the kiosk always boots. Fewer features, but never a crash from missing config.

Speech off → keyboard only
Face off → center-crop

ConfigureAwait(false)

All async Azure calls use ConfigureAwait(false) to prevent deadlocks on the WPF UI thread.

Applied throughout Face &
Speech service impls

Structured Logging

Serilog logs every activation, fallback choice, retry, and cancellation to rolling files.

logs/idphoto-{date}.log
Debug for Tech901 namespace

08

Deployment Scenarios

Development Machine

Dev

Credentials stored in .NET User Secrets, scoped to the developer's machine. Never checked into source control.

# Provision + store secrets
$ ./infra/deploy.ps1 -Env dev -Location eastus
# Destroy resources + purge soft-deletes
$ ./infra/teardown.ps1 -Env dev

Kiosk Machine

Production

Machine-level environment variables. Verified by the diagnostic script before launch.

# Install app + set Azure env vars
$ ./infra/Install-Kiosk.ps1 -ConfigureAzure
# Verify env vars are present
$ ./infra/Test-AzureConfig.ps1
